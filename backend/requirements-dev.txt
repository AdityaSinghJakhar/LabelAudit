# Test/dev dependencies on top of requirements.txt.

# Deliberately does NOT pull in paddlepaddle/paddleocr -- that stack is
# ~1 GB, needs a matching numpy<2 ABI across scipy/opencv/scikit-image
# (see requirements.txt's own comment), and is unnecessary for testing
# anything except ocr_service._get_engine() itself. Every other test
# (rules, field extraction, spatial extraction, registry matching, the
# API layer) drives the pipeline with a stubbed OcrResult instead of a
# real PaddleOCR call -- see tests/conftest.py's `stub_ocr` fixture.
#
# Install with:
#   pip install -r requirements.txt -r requirements-dev.txt
# or, for a quick local run that skips the OCR stack entirely, just:
#   pip install -r requirements-dev.txt -e ../labelguard
# and monkeypatch/stub app.services.ocr_service as the tests do.
